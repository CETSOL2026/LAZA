================================================================================

- O registro aparecia no Cloudflare como tipo Tunnel, apontando para
  Tunnel_Alteryx.

- Foram preservadas as rotas:
  - altorc.way4u.com.br;
  - novoapp.way4u.com.br;
  - organizze.way4u.com.br.
- Depois foi criado/ajustado o CNAME:
  Type: CNAME
  Name: lazadev
  Target: laza-dev.pages.dev
  Proxy status: Proxied
  TTL: Auto

Resultado:
- Custom domain ficou active;
- Verification active;
- Validation active;
- Site passou a operar sem depender da maquina local.

Rollback documentado:
E possivel voltar ao estado anterior recriando o public hostname
lazadev.way4u.com.br no Tunnel_Alteryx ou apontando o DNS de volta para o
target do tunel, desde que o servico local esteja rodando.

Hi LAZA team,

- This is a static/publishable MVP version, generated from the data and
  indicators already prepared during the project.

  Cloudflare at this stage.

- The current Admin protection uses simple edge authentication on Cloudflare
