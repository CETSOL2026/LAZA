# LAZA AI Insight Cards

> Created on 20 July 2026 for LAZA-046. This is the first MVP implementation
> of AI-ready insight cards.

## Implementation approach

The current version does **not** call an external AI model. Insights are
generated by local deterministic rules over Gold/API data so every card remains
traceable, testable and reviewable.

Each card preserves:

- title;
- narrative summary;
- metric;
- period;
- source;
- quality score;
- generation mode;
- rule id;
- review status;
- minimum subscription plan;
- navigation target.

## Governance boundary

This implementation is suitable for MVP demos and commercial discussion because
it is explainable and source-backed. Before using generative AI in production,
LAZA should define:

- approved prompts and output schema;
- human review workflow;
- hallucination and source-attribution guardrails;
- model/provider decision;
- retention policy for prompts and outputs;
- audit trail for accepted/rejected insights.
